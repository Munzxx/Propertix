# Kasboek

Eenvoudige administratie voor een zzp-webshop met de kleineondernemersregeling (KOR).

- Overzicht met een meter voor de KOR-grens van € 20.000 per kalenderjaar
- Inkomsten (bruto omzet en transactiekosten apart), uitgaven (met zakelijk percentage en bon) en uren
- CSV-export per jaar

`index.html` is één zelfstandig bestand. Het is gemaakt als Claude-artifact en slaat gegevens op via de opslag van dat artifact, niet in dit bestand. Dit bestand bevat dus alleen de code. Bewaar je boekingen met de CSV-export.
